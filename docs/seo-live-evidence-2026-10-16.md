## 3. GA4 — زيارات وأحداث

المصدر: `googleanalytics4`، Property `547488425`، عبر Windsor.ai.

- **أغسطس 2026:** 25 جلسة، و46 مشاهدة صفحة. جمع `active_users` يوميًا **ليس** عدد المستخدمين الفريدين للفترة.

- استعلام الأحداث للفترة **1–15 أكتوبر** أعاد `page_view=6`، و`user_engagement=3`، و`session_start=2`؛ **لم يظهر `whatsapp_click` في الصفوف**.
- غياب حدث واتساب في هذه العينة الصغيرة لا يثبت فشل الكود، كما أن نجاح اختبارات المتصفح لإطلاق `gtag` لا يثبت استقبال Google Analytics للحدث فعليًا. حدث `whatsapp_click`، عندما يظهر، يدل على *نية بدء تواصل* فقط وليس عميلًا مؤهلًا أو عملية بيع.

## 5. إجراءات لا ينفذها هذا التحديث آليًا

1. مراجعة Google Search Console مباشرة، وطلب الفهرسة للروابط المؤهلة فقط بعد التأكد من HTTP 200 وcanonical وسلامة المحتوى.
2. مطابقة **33 عنوانًا** في Sitemap مع «Submitted/Discovered» داخل Search Console بعد آخر إعادة جلب.
3. اختبار حقيقي **بموافقة التحليلات** ثم مراقبة Realtime/DebugView؛ عدم تصنيع جلسات أو تحويلات أو تضمين بيانات شخصية لتجميل الأرقام.
4. توفير مصدر موثوق لحجم الكلمات وصعوبتها لمصر والسعودية، وعدم اختلاق أرقام البحث.
5. استخدام صور حقيقية معتمدة فقط؛ عدم تصوير بيانات عملاء أو الادعاء بأن نموذج تصميمي هو واجهة تشغيل حية.
6. استكمال الروابط الخارجية الطبيعية والتدقيق التحريري بوسائل شرعية، ثم إعادة قياس الأداء الفعلي عند اتساع العينة.

**سجل الشفافية:** هذا الملف أدلة وقرارات فقط؛ إنشاؤه/دمجه لا يغير إعدادات GA4 أو Search Console أو Cloudflare أو المحتوى الذي يراه العميل. نتيجة كل مهمة لا تتحول إلى «مكتملة» إلا بالدليل المحدد لها.
