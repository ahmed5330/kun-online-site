# سياسة Visual SEO والصور في كن أونلاين

## قرار إبداعي ملزم
- ممنوع تمامًا ظهور وجوه أشخاص في **أي صورة جديدة**، سواء صورة حقيقية أو مرسومة أو مولّدة بالذكاء الاصطناعي. لو الصورة مش واضحة أو يحتمل ظهور وجه، **تترفض**.
- نستخدم بدلًا منها صور منتجات وتغليف، عناصر واجهات ونظام **مجهولة البيانات**، مخططات، أجهزة، رسوم هندسية ومجسمات بدون أشخاص.
- ممنوع عرض بيانات عملاء أو واجهات تشغيل حقيقية غير معتمدة؛ لقطات السيستم يطبق عليها مسار الموافقة القائم `scripts/system-screenshots.mjs`.
- كل صورة مستوردة يدويًا تحتاج مراجعة بشرية للمحتوى والحقوق والخصوصية وعدم وجود وجوه. لا يُعتبر تحليل أسماء الملفات أو فحص SVG إثباتًا آليًا لكشف الوجوه.

## نظام التصميم
- ألوان البراند: كحلي `#092d53`، أزرق `#10549a`، أخضر `#74d64e`، وأسطح فاتحة للوضوح.
- لكل مقال صورة **معبرة عن الموضوع** وليست تكرارًا حرفيًا للشعار أو رسمًا غير ذي صلة.
- تجنب الحشو النصي داخل الصورة، وادعاءات المبيعات أو نتائج غير موثقة. ينبغي أن يكون الرسم مفيدًا وحده ومتصلاً بنص الصفحة.
- أغلفة المقالات: 1200×630 PNG أساسي + 1200×630 WebP و640×336 WebP لعرض أسرع.
- رسم الغلاف الافتراضي يتم من أشكال هندسية فقط في `scripts/generate-approved-covers.py`، ولا يستورد صور وجوه أو صورًا من الإنترنت.

## SEO والتوافق
- اسم الملف وصفي ومطابق للـ slug، وصورة الغلاف مرئية داخل `<img src>` وليس CSS background.
- كتابة `alt` يصف ما يظهر في الصورة فعلًا باللغة العربية، دون حشو كلمات مفتاحية؛ `width` و`height` لمنع اهتزاز الصفحة.
- الصورة الأساسية فوق الطية لا يتم تأجيلها إن كانت عنصر LCP؛ الصور داخل قوائم المقالات يمكن تحميلها `lazy`.
- `og:image` و`og:image:alt` و`twitter:image` و`BlogPosting.image` يجب أن تشير إلى الصورة الأساسية ذات الصلة؛ `sitemap.xml` يذكر صور المقالات والأصول البصرية المعتمدة.
- لا يُعدل `canonical` أو `robots.txt` أو محتوى SEO/GEO التحريري من مسار الصور دون مراجعة عامة.
- الأداء يُقاس من PageSpeed / Core Web Vitals، والوصول والفهرسة من Search Console وصور البحث؛ إضافة الصورة للـ sitemap **لا تضمن الفهرسة**.

## المراجعة والتسليم
1. مراجعة موضوع الصورة وملاءمتها للمقال / الخدمة.
2. مراجعة صريحة **عدم وجود أي وجه**، إلى جانب الملكية والخصوصية وغياب البيانات غير الصحيحة.
3. فحص حجم ووضوح الصورة على الموبايل، النص البديل، بيانات المشاركة، خريطة الصور.
4. تشغيل اختبارات الموقع و`tests/visual-seo.test.mjs` وبوابة المراجع العام SEO/GEO قبل الدمج.
5. بعد النشر فقط، تحقق من HTTP 200 للصور ونتائج Google Images عبر GSC؛ لا يُذكر ظهور فعلي دون بيانات.

المعيار الآلي يمنع تراجع بيانات Image SEO وأصول SVG المضمّنة؛ **تقييم الجاذبية البصرية وفحص الوجوه في أي صور خارج المولّد الآلي يظل مراجعة بشرية لا تدعيها الاختبارات**.
