متطلبات التجربة

  1. جهاز يعمل بنظام Windows.
  2. اسم النشاط ونوع المنتجات وعدد الفروع والأجهزة.
  3. تحديد طريقة استخدام الباركود والطباعة المطلوبة.
  4. إذا كانت المزامنة مطلوبة، مراجعة التفعيل المخصص للفرع وصلاحياته.

قبل ما تبدأ

البرنامج يشغّل خدمة محلية وواجهة متصفح، ولا يحتاج تثبيت Python منفصل. ملفات التفعيل الحالية مشفرة ومخصصة لجهاز محدد، لذلك لا نقدم الحزمة على أنها نسخة جاهزة لكل العملاء.

ليست هناك أسعار تجارية أو اشتراكات أو بوابة دفع مثبتة حاليًا.

اطلب التجربة بشكل مباشر

اضغط على واتساب، واكتب نوع محلك والوظائف التي تريد اختبارها. لا يوجد نموذج وهمي؛ هذا الرابط يفتح وسيلة التواصل المعلنة لكن أونلاين.
